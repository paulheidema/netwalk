NetWalk

Test how strong, fast and reliable your phone's internet is as you walk around Dominica. Three versions to try. They all share the same saved readings, so you can switch any time.

Version 1

Signal Dashboard

Gauges for strength and reliability, a live bar chart, and a small map of today's dots or all-time zones.
Version 2

Coverage Map

Full-screen map with honeycomb zones. Switch between overall, speed and reliability, and between today, yesterday and all time.
Version 3

Daily Walk Report

Plain-English verdict (“Good for video calls”), concentric-ring zones, your best and worst spots, and a report card for each day.
Before you walk
  • Open in Safari and allow Location when asked.
  • Keep the screen on. iPhone pauses web pages when it locks.
  • Turn Wi-Fi off so you're testing Digicel, not the Airbnb's internet.
  • Optional: Share › Add to Home Screen, so it opens like an app.
  • No walk yet? Each version has Load demo walk under settings, so you can see what the maps look like.
