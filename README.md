# NetWalk

Walk-around cellular internet tester for Dominica. One Start walk button; three views (Now, Map, Days) share the same walk and data.

Measures ping, jitter, dropouts and download speed, tags each reading with GPS, and builds coverage zones over days. Readings stay in the phone's browser storage. A walk in progress survives reloads and tab switches; iPhone pauses it while the screen is locked.
