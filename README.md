# NetWalk

Walk-around cellular internet tester for Dominica. Measures ping, jitter, dropouts and download speed, tags each reading with GPS, and builds coverage zones over days.

- `v1.html` Signal Dashboard
- `v2.html` Coverage Map (honeycomb zones)
- `v3.html` Daily Walk Report (concentric-ring zones, day report cards)

All readings stay in the phone's browser storage and are shared between the three versions.
